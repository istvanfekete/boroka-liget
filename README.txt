BORÓKA LIGET WEBOLDAL - FELTÖLTÉSI ÚTMUTATÓ

1. Nyisd meg a tárhely File Manager / Fájlkezelő felületét.
2. Lépj a public_html mappába.
3. A csomag tartalmát töltsd fel úgy, hogy az index.html közvetlenül a public_html mappában legyen.
4. Az űrlap működéséhez nyisd meg a script.js fájlt, és ezt a sort:
   const contactEmail='IDE_IRD_AZ_EMAIL_CIMED';
   írd át a saját e-mail-címedre.
5. Az oldalhoz a fődomainen kérj SSL-t, majd ellenőrizd HTTPS-en.

Tartalom:
- index.html: a teljes egylapos weboldal
- style.css: megjelenés és mobilnézet
- script.js: mobilmenü, animációk, galéria és kapcsolatfelvétel
- assets/: optimalizált képek és a koncepció PDF

Megjegyzés:
Az oldal szándékosan mindenütt előzetes koncepcióként hivatkozik a projektre. A végleges adatok, árak,
elérhetőség és kapcsolati adatok később egyszerűen átírhatók az index.html fájlban.
